## Commandments

- When trying to run things locally, use the version of python found in .venv first
- My preference for the front end is using bun
- When testing the front-end assume the front end is already running, if it isn't, ask me to run it
- This project is intended to be a proof of concept, so don't worry about compatability. Feel free to change file names and rewire things
- I when choosing which packages to use, I want the one that best supports my needs, not the one that has existed for the longer
- When replying to me, skip pleasantries and be concise with your response
